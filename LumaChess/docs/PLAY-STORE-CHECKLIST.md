# LumaChess — Android / Google Play release checklist

- [ ] Test all chess rules, edge cases, accessibility, orientation and small-screen layouts.
- [ ] Test offline install/update behaviour and clear-cache recovery.
- [ ] Test peer-to-peer connection failures and clearly disclose online limitations.
- [ ] Generate the native project with Capacitor and open it in Android Studio.
- [ ] Test on multiple Android versions and at least one physical device.
- [ ] Configure app ID `com.lumachess.game`, version code/name, adaptive launcher icon and splash screen.
- [ ] Provide a public privacy policy and complete Play Console Data safety accurately.
- [ ] Prepare store description, screenshots, feature graphic and content rating.
- [ ] Generate a signed `.aab`; keep the signing credentials backed up privately.
- [ ] Upload to an internal/closed testing track and fix issues before production review.
- [ ] Submit for review; publication depends on Google Play approval.
